# Fedora Hyprdots

Personal Hyprland dotfiles for Fedora Workstation.

## Environment

- Fedora 44
- Hyprland 0.56+
- Waybar
- Rofi
- Kitty
- Mako
- Hyprpaper
- NetworkManager
- PipeWire / WirePlumber

## Features

- Hyprland Lua configuration
- Catppuccin styled Waybar
- Active Wi-Fi SSID and network selector
- VPN shortcut
- Bluetooth shortcut
- MPRIS media / browser media title
- Screenshot to clipboard
- Volume and brightness controls
- Hyprlock
- Multi-monitor support

## Notes

Originally based on yurihikari/garuda-hyprdots and adapted for Fedora.
